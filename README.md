# 🦠 COVID-19 Data Analysis

## 📌 Project Overview

This project analyzes global COVID-19 data to understand the spread and trends of the pandemic across different countries. The analysis focuses on comparing **India, the United States, and Brazil** using real-world COVID-19 data.

The project uses Python to perform data cleaning, filtering, aggregation, time-series analysis, and data visualization.

---

## 🎯 Objectives

- Analyze COVID-19 total cases across selected countries.
- Compare daily new COVID-19 cases.
- Identify COVID-19 growth trends during 2020.
- Calculate a 7-day moving average to understand underlying trends.
- Compare total cases and deaths across India, the United States, and Brazil.

---

## 📊 Dataset

The dataset used is the **Our World in Data COVID-19 dataset**.

Key columns used in the analysis:

- `location`
- `date`
- `total_cases`
- `total_deaths`
- `new_cases`

- Total COVID-19 cases over time.

## 💡 Key Insights

- The **United States recorded the highest number of COVID-19 cases** among the selected countries during 2020.
- All three countries experienced significant increases in cases during peak periods.
- Daily new cases showed considerable fluctuations, indicating multiple waves of infection.
- The **7-day moving average** helped reduce daily fluctuations and provided a clearer view of overall trends.
- India and Brazil showed significant growth patterns during their respective peak periods.
